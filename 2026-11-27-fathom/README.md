# Fathom

Minesweeper with an exact probabilistic solver, a no-guess generator and a heat-map web UI.

**Status:** Phase 5 complete — 35 unit/integration tests + 18-check browser e2e + `test/demo.sh` all green.
Stretch features, review, benchmarks and the full write-up land in later phases. See `PLAN.md`.

Quick start: `node serve.js` then open http://localhost:8080/ — `node --test "test/*.test.js"` runs the tests.
