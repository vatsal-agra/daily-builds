# Lumina — Ray Tracer / Path Tracer

> **Status: Phase 1 — Plan complete. Building now.**

A from-scratch physically-based renderer in pure Python: Whitted ray tracing,
Monte Carlo path tracing with global illumination, BVH acceleration, reflections,
refractions, depth-of-field, OBJ mesh loading, and an interactive HTML scene editor.

See [PLAN.md](PLAN.md) for full architecture and feature list.
