# Casement

*Status: Phase 1 (plan) complete. Core build in progress.*

A from-scratch HTML/CSS layout and rendering engine in pure Python: HTML
parser, CSS parser + cascade, a block/inline + flexbox layout engine, and a
software rasterizer that writes real PNGs. See `PLAN.md` for the full design
and feature list, and `LEDGER.md` (repo root) for how this fits into the
rest of the daily-build history.

This README will be filled in with run instructions, the full feature list,
and verification results as each phase lands.
