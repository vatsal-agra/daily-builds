# Trove

*Status: Phase 1 complete (planning). Core build in progress.*

A from-scratch full-text search engine — tokenizer, Porter stemmer,
inverted index, BM25 ranking, a real boolean/phrase query language, and
Levenshtein-based fuzzy correction — implemented in pure Python.

Its demo corpus is this repository's own history: the READMEs of the 36
daily builds that came before it, made properly searchable for the first
time.

See [PLAN.md](./PLAN.md) for the full architecture and feature list.
This README will be filled in with usage instructions as the build
progresses through each phase.
