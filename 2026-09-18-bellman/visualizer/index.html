Bellman / a from-scratch reinforcement learning lab

Every algorithm here exploits the same recursive identity — the value of a state is the immediate reward plus the discounted value of wherever you land next — a different way each time: exact dynamic programming, sampled temporal-difference control, and self-play. Data on this page is not staged: it is the literal output of viz_export.py re-running every algorithm end to end.
