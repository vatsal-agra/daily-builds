# Bellman

A reinforcement-learning laboratory built entirely from scratch in pure
Python — no NumPy, no PyTorch, no `gym`/`gymnasium`. Tabular TD control
(Q-Learning, SARSA), a dynamic-programming oracle (Value/Policy Iteration)
that computes the *provably* optimal policy as ground truth, a from-scratch
CartPole physics simulation controlled by a REINFORCE policy-gradient agent
(backed by a hand-rolled scalar autodiff engine), and an interactive HTML
visualizer.

full concept, architecture, and feature list. Implementation starts next.
