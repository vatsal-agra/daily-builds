# Glean

*Status: Phase 1 — planning complete, core build starting next.*

A from-scratch full-text search engine — inverted index, BM25 ranking, boolean/phrase
queries, and typo-tolerant fuzzy matching — with no search library dependency. Its
flagship demo indexes this very repository's history of daily builds so every prior
`README`/`PLAN`/`REVIEW`/`LEDGER` entry becomes instantly searchable.

See [PLAN.md](./PLAN.md) for the full concept, architecture, and feature list.

This README will be filled in with usage instructions as each phase completes.
