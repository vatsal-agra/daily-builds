# Backjump

A from-scratch **CDCL SAT solver** (conflict-driven clause learning) in pure Python.

> **Status: Phase 1 — planning complete.** See [PLAN.md](PLAN.md) for the concept,
> architecture, and full feature list. Build in progress.

## What it will be
A modern SAT solver — two-watched-literal propagation, 1-UIP clause learning,
non-chronological backjumping, VSIDS, Luby restarts — with verified UNSAT proofs,
real puzzle encoders (Sudoku / N-Queens / graph colouring), and an interactive
implication-graph visualizer.

See [PLAN.md](PLAN.md) for details.
