# Loom

**Status: Phase 1 (plan) complete. Build in progress.**

A GPT-style decoder-only Transformer language model built entirely from
scratch — its own autograd tensor engine, its own BPE tokenizer, its own
training loop — in pure Python + NumPy (no PyTorch/TensorFlow/JAX).

See [PLAN.md](./PLAN.md) for the full architecture and feature list.

This README will be filled in with usage instructions, the full feature
list, and results as each phase completes.
