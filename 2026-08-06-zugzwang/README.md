# Zugzwang

A chess engine built from scratch in pure Python — board representation,
legal move generation, alpha-beta search, evaluation, and a playable CLI
and web UI. No chess library dependency anywhere in the stack.

**Status: Phase 1 (plan) complete.** See [`PLAN.md`](./PLAN.md) for the
full architecture and feature list. Implementation in progress — this
README will be filled in with run instructions, the full feature list,
and design notes as each phase completes.
