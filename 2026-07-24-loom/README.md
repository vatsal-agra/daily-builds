# Loom

A GPT-style language model built entirely from scratch — hand-derived
reverse-mode autodiff, a from-scratch BPE tokenizer, a decoder-only
transformer, and an Adam optimizer, trained on the public-domain Tiny
Shakespeare corpus.

**Status: Phase 1 (plan) complete.** See [PLAN.md](PLAN.md) for the
architecture and feature list. Implementation in progress — this README
will be filled in with usage instructions as each phase lands.
