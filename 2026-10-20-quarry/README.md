# Quarry
A from-scratch memory allocator (`malloc`) in C with an `LD_PRELOAD` drop-in, a heap-debug mode, and an
allocation trace recorder / replay simulator that compares allocator designs.

**Status: phase 1 of 6 — plan written.** See [PLAN.md](PLAN.md) for the concept, architecture and the feature
list (4 required, 4 stretch). Full documentation arrives with the ship phase.
