Braid

A from-scratch CRDT (Replicated Growable Array) text editor. Every pane below is an independent replica connected by a simulated, adjustable, breakable network — type in one, watch it merge into the others. No server, no library: the merge algorithm is src/rga.js.

Undo/redo is causal — it only ever affects the exact character(s) that specific peer inserted or deleted, so undoing your own edit stays correct even after other peers have typed around it. Try: split into two partitions, edit both sides, then heal — watch the histories merge deterministically instead of one side clobbering the other. Run npm test for the 100-scenario randomized convergence proof behind this.
