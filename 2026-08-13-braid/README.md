# Braid

*Status: Phase 1 — planning complete, build starting.*

A from-scratch CRDT (Replicated Growable Array) collaborative text editor
with an adversarial network simulator, built entirely in vanilla JS with
zero dependencies.

See [PLAN.md](./PLAN.md) for the full concept, architecture, and feature
list. This README will be filled in with usage instructions as each phase
completes.
