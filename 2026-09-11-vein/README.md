# Vein

A from-scratch Proof-of-Work blockchain — real secp256k1 ECDSA, a UTXO
ledger with a tiny Script VM, PoW mining with difficulty retargeting, and
a multi-process P2P gossip network that reconciles forks by cumulative
work, the way real Bitcoin nodes do.

**Status: Phase 1 (Plan) complete.** See [`PLAN.md`](PLAN.md) for the full
architecture and feature list. Implementation starts next in Phase 2.
