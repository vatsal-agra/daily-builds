# Ashenkeep

> Status: **Phase 1 — Plan.** See [`PLAN.md`](./PLAN.md) for the full design.
> Nothing is implemented yet; this README will grow with each phase.

A browser-playable roguelike dungeon crawler built entirely from scratch in
vanilla JavaScript — procedural dungeons, real field-of-view, A* enemy AI,
turn-based combat, and a full loot/inventory system.
