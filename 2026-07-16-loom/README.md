# Loom

A tiny GPT-style language model built from scratch in Python: a hand-rolled
tensor autodiff engine, a byte-pair-encoding tokenizer, a decoder-only
Transformer, an Adam-trained optimizer loop, and autoregressive sampling —
no PyTorch, no JAX, no autograd library.

**Status: Phase 1 (plan) complete.** See [PLAN.md](PLAN.md) for the full
architecture and feature list. Implementation in progress — this README
will be filled in with usage instructions as each phase lands.
