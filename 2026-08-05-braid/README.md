# Braid

*Status: Phase 1 (plan) complete. Build in progress.*

A real-time collaborative text editor whose consistency guarantee comes
from a from-scratch **CRDT** (Conflict-free Replicated Data Type) — no
OT, no central sequencer, no CRDT library. See [PLAN.md](./PLAN.md) for
the full concept, architecture, and feature list.

This README will be filled in with usage instructions, the full shipped
feature list, and a "where a human could take this next" section as each
build phase completes.
