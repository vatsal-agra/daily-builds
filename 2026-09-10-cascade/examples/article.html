Building a Browser Engine From Scratch

Filed under experiments, one afternoon at a time

Every page on the web goes through the same pipeline before a single pixel reaches your eyes an HTML parser builds a tree, a CSS engine works out which rules apply to which nodes, and a layout engine turns all of that into boxes with real positions and sizes.

The cascade is not a bug. It is the whole point: many rules, one final answer, decided by specificity, source order, and importance.

This build does exactly that from first principles a tokenizer, a tree builder with real auto-close rules, a selector matcher with specificity, a block and inline formatting context with margin collapsing, and a flexbox subset.

  • HTML parsing with recovery from malformed markup
  • CSS selectors, specificity, and inheritance
  • Block layout with the real box model
  • Text wrapping into line boxes
