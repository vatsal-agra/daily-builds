# Cascade

A browser layout engine built entirely from scratch: HTML parsing, CSS
parsing + the cascade, block/inline layout with margin collapsing, a
flexbox subset, and a from-scratch PNG rasterizer — no browser, no HTML/CSS
library, no imaging library.

**Status: Phase 1 (planning) complete.** See `PLAN.md` for the full concept,
architecture, and feature list. Implementation starts in Phase 2.
