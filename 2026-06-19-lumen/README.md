# Lumen — Physically-Based Path Tracer

> **Status: Phase 1 complete (PLAN)**

A path tracer built from scratch in Python. See PLAN.md for the full architecture and feature list.

## Quick Start

```bash
python3 lumen.py demo
```

## Planned Features

- Sphere, Quad, Box geometry + BVH acceleration
- Lambertian, Metal, Dielectric (glass), DiffuseLight materials
- Monte Carlo path tracing with Russian roulette
- Cornell box, metallic spheres, glass caustics scenes
- Depth of field (stretch)
- Procedural textures: checker + Perlin noise (stretch)
- HTML gallery viewer
- Tiled rendering with multiprocessing
