# Cryptex — Cryptography Workbench

**Status: Phase 1 (Planning) complete**

A from-scratch cryptography toolkit implementing AES-256, SHA-256/HMAC, RSA-2048, and P-256 ECDH/ECDSA in pure Python with no crypto dependencies. See PLAN.md for full architecture.
